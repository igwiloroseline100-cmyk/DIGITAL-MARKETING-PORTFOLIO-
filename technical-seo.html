TECHNICAL SEO

Solving the technical problems that can affect search visibility.

Technical SEO is about making sure search engines can discover, crawl, understand and index the pages that matter.

PROBLEMS WE SOLVE

What can go wrong?

These are the technical problems I investigate and diagnose.

01

CRAWLABILITY

Crawl Problems

Search engines may struggle to efficiently access important pages because of blocked resources, crawl traps, poor linking or inefficient URL structures.

Robots.txt • Crawl budget • Crawl traps
02

INDEXATION

Indexing Problems

Important pages may be discovered but still fail to appear in search results because of indexation restrictions or conflicting signals.

Noindex • Indexability • Search Console
03

DUPLICATION

Duplicate Content & URLs

Multiple URLs can represent the same or very similar content, creating unnecessary crawling and confusing search engines about the preferred page.

Canonicals • Duplicate URLs • Parameters
04

WEBSITE STRUCTURE

Orphan & Poorly Linked Pages

Valuable pages can become difficult to discover when they have little or no internal linking support.

Internal linking • Orphan pages • Site structure
05

URL MANAGEMENT

URL & Redirect Issues

Broken URLs, incorrect redirects, redirect chains and loops can create poor user experiences and unnecessary crawling.

301 • 302 • 404 • 5xx • Redirect chains
06

FACETED NAVIGATION

URL Explosion

Filters and URL parameters can create thousands of unnecessary URL combinations and waste crawl resources.

Facets • Parameters • Crawl control
07

TECHNICAL PERFORMANCE

Performance Problems

Slow or unstable pages can create a poor user experience and affect important technical performance signals.

LCP • INP • CLS • Mobile
08

JAVASCRIPT SEO

Rendering Problems

JavaScript-heavy websites can create problems when important content or links are not properly available to search engines.

CSR • SSR • Rendering • Googlebot
09

SITE MIGRATIONS

Migration Problems

Website redesigns, domain changes and URL changes can cause traffic and indexation problems when redirects and technical signals are not handled correctly.

Redirect mapping • HTTPS • URL changes
10

INTERNATIONAL SEO

International SEO Issues

Websites serving multiple countries or languages need clear signals so search engines understand which version belongs to which audience.

Hreflang • Language • Regional targeting
11

STRUCTURED DATA

Schema & Structured Data

Incorrect or incomplete structured data can prevent search engines from properly understanding eligible page information.

Schema • Validation • Search features
12

SERVER & TECHNICAL HEALTH

Server Errors

Server-side failures can prevent pages from being successfully accessed by users and search engines.

500 • 502 • 503 • 504

HOW I INVESTIGATE

Problem → Evidence → Diagnosis → Recommendation

A technical issue is not just an error to tick off a list. I look at the evidence, understand the cause and determine how the problem can affect important pages.

The final recommendation should be practical, prioritised and connected to the actual problem.
